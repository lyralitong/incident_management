# 外部副作用门

## 默认策略

文档发布、文档修改、DC 发送和其他外部写操作默认停在 `APPROVAL_REQUIRED`。审批信息必须包含目标对象、内容摘要、收件人/资源 ID、幂等键和预期结果。

已授权的定时 workflow 可以跳过逐次询问，但不能跳过收件人校验、幂等检查、服务端回执和回读核验。

## 幂等键

幂等键由业务对象、动作和版本组成。例如改进项提醒使用：

```text
事故ID + 改进项ID/规范化文本 + 负责人 + 截止日期 + 提醒节点
```

键对应的成功记录必须持久化。失败记录可以重试，成功记录不得重复发送。

## 结果分类

只允许使用以下结果：`sent`、`skipped`、`pending`、`failed`、`verified`。生成消息草稿、调用接口超时或服务端未确认都不能写成 `sent`/`verified`。
