# 重试和失败恢复

## 可重试错误

网络断开、DNS、网关 5xx、临时限流、连接超时和进程中断默认可重试；参数错误、权限拒绝、数据结构错误和业务规则冲突不可盲目重试。

退避序列为 1、2、4、8、16 分钟。每次重试都保存错误码、请求摘要和尝试次数；超过上限后转为 `FAILED` 或 `BLOCKED`，保留人工处理清单。

## 有副作用的操作

发送、发布、修改、创建等操作必须先查询是否已完成。无法确认时使用已有资源 ID 或幂等键回读，不得直接重复创建或发送。只有明确的服务端成功回执和回读结果才算成功。

## 局部失败

多个指标、多个候选日期或多条改进项互不依赖时，分别保存状态并继续处理其他项目。最终结果必须列出成功、待定、阻断和失败项，不能因为一个局部失败声称全部完成。
